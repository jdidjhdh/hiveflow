# HiveFlow v0.1.0 (Alpha)

**Multi-agent coordination & HITL layer** — first public release.

## Highlights

- **Core (`hiveflow-core`)** — Event bus, scheduler, blackboard, HITL, RAG, MCP, guards, checkpoints
- **Agent (`hiveflow-agent`)** — NL TaskGraph planning, ReAct workers, cognitive orchestration
- **Studio** — Self-hosted FastAPI + React UI (Orchestrator, Approvals, Analytics, Replay)
- **745+ tests** across Core, Agent, and Studio (CI gated at ≥60% coverage)

## Install (GitHub Release — no PyPI required)

Download wheels from [GitHub Releases](https://github.com/jdidjhdh/hiveflow/releases/tag/v0.1.0) or:

```bash
git clone https://github.com/jdidjhdh/hiveflow.git
cd hiveflow
pip install -e packages/core -e packages/agent
python examples/01_hello_hiveflow.py
```

## Docker

```bash
docker compose up --build
# Studio: http://localhost:5173  ·  API: http://localhost:8000
```

GHCR images: `ghcr.io/jdidjhdh/hiveflow-studio-api:0.1.0`, `ghcr.io/jdidjhdh/hiveflow-studio-web:0.1.0`
